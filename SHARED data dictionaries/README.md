# SHARED Data Dictionaries

Dieser Bereich enthält Data Dictionaries, die durch den zuständigen
Data-Dictionary-Owner zur Koordination oder fachlichen Prüfung freigegeben
wurden. Sie sind noch nicht für die operative Nutzung autorisiert. Blocking
Errors sind vor der Aufnahme zu beheben. Jede Datei ist im Unterordner der
verantwortlichen Organisation abzulegen.

Massgeblich sind die
[Housekeeping-Regeln](../docs/repository-housekeeping.md).
