# Validator-Regressionstests

Dieser Ordner enthält ausschliesslich automatisierte Python-Tests für die
Validierungslogik. Die GitHub Action führt diese Tests vor jedem
Validierungslauf aus.

Hier dürfen keine Strukturvorlagen oder organisationsspezifischen Data
Dictionaries abgelegt werden. Solche Dateien gehören nach Status und
verantwortlicher Organisation unter `WIP data dictionaries/`,
`SHARED data dictionaries/`, `PUBLISHED data dictionaries/` oder
`ARCHIVED data dictionaries/`.
