# PUBLISHED Data Dictionaries

Dieser Bereich enthält konkrete Versionen, die durch den zuständigen
Data-Dictionary-Owner nach fachlicher Qualitätssicherung ausdrücklich zur
Nutzung freigegeben wurden. Eine erfolgreiche technische Validierung allein
ist keine Publikationsfreigabe. Jede Datei ist im Unterordner der
verantwortlichen Organisation abzulegen.

Massgeblich sind die
[Housekeeping-Regeln](../docs/repository-housekeeping.md).
